# Sources and originality

TinyVerify separates registration, corporate licensing, public complaint listings and selected status monitoring. These are different source scopes and are not interchangeable claims.

## Official record sources

- [UK Companies House](https://find-and-update.company-information.service.gov.uk/) supplies the historical company-registration samples. Registration alone does not establish professional licensing, expiry or discipline.
- [ABN Lookup](https://abr.business.gov.au/) supplies the historical ABN-registration sample. An active ABN is not trading permission or identity assurance.
- [Florida DBPR](https://www.myfloridalicense.com/) supplies the selected Real Estate Corporation licence and its separate public complaint listing. [Exact selected detail](https://www.myfloridalicense.com/portalsearches/VerifyLicensee/LicenseDetail?ID=B1B7828012AA269780F1999CA2AC6DF5).

Selected public corporate values, URLs, dates and complaint rows are retained with their evidence boundary. Raw site HTML, third-party minified scripts, complete source pages, cookies and tokens are excluded. No affiliation with the selected businesses or regulators is claimed.

## TinyFish contracts

The implementation was built against official documentation for [Agent requests](https://docs.tinyfish.ai/agent/api/agent.md), [structured output](https://docs.tinyfish.ai/agent/api/agent/structured-output.md), [run readback/cancellation](https://docs.tinyfish.ai/agent/api/runs.md), [Fetch](https://docs.tinyfish.ai/fetch-api/reference.md) and [Monitor](https://docs.tinyfish.ai/monitor/api-reference.md). These links document the contracts used; this local packaging pass does not establish today's pricing or a reusable provider authorization.

Agent enables native form navigation and selected public history. Fetch independently corroborates the chosen licence. Monitor supplies two observations of that same exact GET detail. Parsing, type validation, exports, finite controls and the saved-review interface are local project code. Dependency versions are pinned in [package-lock.json](../package-lock.json); dependency licences remain with their packages.

## Original-work boundary

This release candidate packages the project's reviewed local implementation and genuine selected evidence. The interface and report are project-created. Synthetic fixtures are labelled in demos and tests, not presented as live observations. No vendor website source bundle is redistributed. The demo is an edited walkthrough of the project's saved-review page with editorial captions and a cursor asset, not an official registry recording.

No repository licence was present in the reviewed source. This package does not invent a licence, claim third-party endorsement or grant an open-source permission. It is not a formal contest originality ruling; eligibility and the final external original-work review remain release gates.
