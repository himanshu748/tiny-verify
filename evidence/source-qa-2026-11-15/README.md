# Independent public source check

The [ordinary-source-qa.json](ordinary-source-qa.json) receipt records 20/20 selected public-field checks from signed-out Chrome on 15 November 2026. It matched the actual chosen licence and all seven visible public complaint rows, including four explicit Fine/Sanctions descriptions. It is ordinary browser corroboration, not new TinyFish transport evidence.

[verification.json](verification.json) identifies the original check and its privacy boundary. [expected-public-record.json](expected-public-record.json) contains the selected public values used for comparison. No raw HTML, screenshot of the regulator page, cookies, form data, address or associated-person export is included. The recorded source times remain historical when this package is opened later.
